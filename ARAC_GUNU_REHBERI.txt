2) ARAÇ GÜNÜ NE KULLANACAĞIZ
----------------------------------------------------------------

--- 2.1) Kod güncelleme + Docker image hazırlama (araca gitmeden önce, buradan) ---

    cd ~/Desktop/carla-ros2-ws

    # 1. Kodu deploy klasörüne senkronla (önce --dry-run ile bir bak, sonra gerçek)
    ./export_deploy.sh --dry-run
    ./export_deploy.sh

    # 2. Docker image'ını (yeniden) build et
    cd ~/robotaksi_deploy
    docker build -t robotaksi_humble:latest .

    # 3. Image'ı dosyaya paketle
    docker save -o robotaksi_humble.tar robotaksi_humble:latest

    # 4. Araca gönder (SSH/SFTP)
    scp robotaksi_humble.tar smart@192.168.30.100:/home/smart/

--- 2.2) Araçta (SSH ile bağlanıp) ---

    ssh smart@192.168.30.100
    sudo docker load -i robotaksi_humble.tar

    sudo mkdir -p /home/smart/Permanent/maps \
      /home/smart/Permanent/neuravix_kayit

    sudo docker run -d --gpus all --network host --ipc=host --privileged \
      -v /dev:/dev \
      -v /home/smart/Permanent/maps:/root/maps \
      -v /home/smart/Permanent/neuravix_kayit:/root/neuravix_kayit \
      -e ROS_DOMAIN_ID=<araçtaki_gerçek_değer> \
      --name robotaksi_container robotaksi_humble:latest tail -f /dev/null

    ÖNEMLİ - araçta container'dan ÖNCE/paralelde çalışması gerekenler:
      - Aracın kendi CAN köprüsü (bizim paketimiz değil, aracın kendi
        paketi): "smart_can_stuff"
          ROS1: roslaunch smart_can_stuff start_can_bus.launch
          ROS2: ros2 launch smart_can_stuff can_launch.xml
      - Güncel image varsayılanı Fast DDS'tir
        (RMW_IMPLEMENTATION=rmw_fastrtps_cpp) ve araç host'u da Fast DDS ile
        çalışır. Cyclone yalnız iki taraf da birlikte Cyclone'a geçirilecekse
        kullanılacak yedektir; iki tarafta RMW aynı olmalıdır.
      - ROS_DOMAIN_ID her iki tarafta da AYNI olmalı. Araçtaki değeri
        önce öğrenin: echo $ROS_DOMAIN_ID

--- 2.3) Container içinde çalıştırılacak node'lar ---

    Container açıldığında bashrc otomatik ROS'u source ediyor.

    ros2 run neuravix_ros2 lane_follower --ros-args \
        -p camera_topic:=<gerçek zed2 topic'i>
    ros2 run neuravix_ros2 tabela_tespit --ros-args \
        -p camera_topic:=<gerçek zed2 topic'i>
    ros2 run neuravix_ros2 obstacle_lidar --ros-args \
        -p lidar_topic:=<gerçek velodyne topic'i>
    ros2 run neuravix_ros2 neuravix_control_real

    ÇALIŞTIRILMAYACAKLAR (CARLA'ya özel, araçta anlamsız/gereksiz):
      - neuravix_control   (CARLA'ya konuşan sim node'u - bunun yerine
                             neuravix_control_real kullanılacak)
      - tabela_overlay (camera_overlay_node.py)
      - neuravix_kontrol.py (bağımsız CARLA test scripti)

--- 2.4) Kod bir şey değişince ---

    Yukarıdaki 2.1'deki 4 adımı (export -> build -> save -> scp) ve
    2.2'deki docker load + run adımlarını TEKRARLAYIN. export_deploy.sh
